# Arcanea Desktop Layer

High-quality Arcanea-tuned experience on the Hermes Electron desktop.

## New UI Elements
- ArcaneaCreationBar: New Session | New World | New Character | New Book | Library | Content Studio
- Integrated model recommender (Grok-first for image/video/creative)
- WorldBuilder with research (MCP + mythology/lore simulation)
- Library (worlds/characters/books)
- Content Studio (ties directly to Publishing House skills)
- Progression tracking + badge system (documented)

## How it works
- Powered by Hermes core (chat sessions, profiles, skills, MCPs).
- Launch tailored chats for creation flows.
- Switch to publishing-house profile for full swarm.
- Recommended models surfaced.

## Access (current)
- Import and render ArcaneaView from src/arcanea/index.tsx
- Extend /artifacts for Library or add /arcanea route.
- Full integration: add CreationBar to shell or command-center.

See master plan for remaining polish and packaging.
